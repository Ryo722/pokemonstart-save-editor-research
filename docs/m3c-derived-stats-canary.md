## Source and calculation evidence

Primary pinned source: `kapibarasan000/CFRU-JP` commit `e24a16fe39e27ae162faf5b78596d1f3df18489d`:

- [`src/build_pokemon.c`](https://github.com/kapibarasan000/CFRU-JP/blob/e24a16fe39e27ae162faf5b78596d1f3df18489d/src/build_pokemon.c) `CalculateMonStatsNew` uses hyper-training-effective IVs, EV/4, EXP-derived level, species base stats, nature mint minus one when nonzero, and adjusts current HP when max HP increases. This proof excludes hyper-training and any max-HP decrease. The selected EV change increases max HP by one, so current HP increases by one under the source rule.
- [`src/Tables/base_stats.c`](https://github.com/kapibarasan000/CFRU-JP/blob/e24a16fe39e27ae162faf5b78596d1f3df18489d/src/Tables/base_stats.c) gives species 1 base HP/Atk/Def/Spe/SpA/SpD `45/49/49/45/65/65`.

The ordinary ±10% integer behavior is supported by [FireRed's decompiled implementation](https://github.com/pret/pokefirered/blob/master/src/pokemon.c), and the private starting record independently matches the resulting Modest values for all five cached stats. The exact PokemonStart candidate still requires the game canary.

The allowed targets are deliberately narrow: mint `0 -> 4` (Adamant effective nature), HP EV `0 -> 80` (within the conservative per-stat limit 252 and total 510), and Attack IV `29 -> 0` (within five-bit 0–31). They are not exposed as general ranges by this proof writer. The source profile's nature is Modest because `personality % 25 = 15`; the starting cached stats agree with the pinned base-stat formula.
