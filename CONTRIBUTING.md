# Contribution boundary

Only original documentation and scripts with clear authorship may be committed. Do not add ROMs, saves, package files, embedded patches, game assets, or extracted executables, even as test fixtures. Tests should use synthetic data or private local inputs excluded from Git. Do not execute a distribution executable blocked by Defender. Record hashes and byte offsets without publishing the underlying copyrighted data. Obtain review before expanding distribution, licensing assumptions, or automatic writes to a user's save.
